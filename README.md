🤖 Rule-Based Chatbot

💬 A Simple Python Chatbot Using Keyword-Based Responses

A beginner-friendly Rule-Based Chatbot developed using Python.
The chatbot analyzes user input, identifies predefined keywords, and generates appropriate responses using if-else decision-making logic.

---

✨ Features

- 👋 Responds to common greetings
- ❓ Answers basic predefined questions
- 🧠 Uses keyword-based decision making
- 🔄 Supports continuous conversation
- ⚠️ Provides fallback responses for unknown inputs
- 👋 Supports chatbot exit commands
- 💻 Simple command-line interface
- 📝 Includes comments explaining the chatbot logic

⚙️ How It Works

The chatbot follows a simple rule-based process:

User Input
    ↓
Convert Input to Lowercase
    ↓
Check Predefined Keywords
    ↓
Match Found?
   ↙       ↘
 YES        NO
 ↓           ↓
Response   Fallback
            Response

For example:

User: hello
       ↓
Keyword "hello" detected
       ↓
Bot: Hello! How can I help you?
