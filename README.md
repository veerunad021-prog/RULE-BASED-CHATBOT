# Rule-Based Chatbot

A simple Python chatbot that responds to user input using predefined keywords and if-else decision-making logic.

## Features

- Responds to common greetings
- Handles basic questions
- Uses predefined keywords
- Provides fallback responses for unknown input
- Supports continuous conversation
- Includes comments explaining the chatbot logic

## Technologies Used

- Python
- If-Else Statements
- String Processing
- Pattern Matching

## How to Run

1. Open the project folder in VS Code.
2. Open the terminal.
3. Run the following command:

```bash
python chatbot.py
